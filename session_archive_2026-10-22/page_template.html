MedCalc-Bench Run Samples

Rows drawn from each run (two scored Correct and two Incorrect where available), with the exact system and user prompt sent, the model's raw output, the answer the parser extracted and the ground truth. Highlighted text is the time-point instruction.

GPT rows come from the 10/22 run (dataset/test_data_10_22.csv, one_shot_10_17_2026.json), where the time-point instruction follows the opening instruction. Open-model rows come from the fixed vLLM re-runs (one-shot: no-criteria examples), which placed it at the end of the system prompt. For open models the two messages shown were wrapped in each model's chat template before generation. Meditron and PMC-LLaMA one-shot rows are left out because their example was shortened with a tokenizer not available here; PMC-LLaMA notes are shown as the run used them, cut to 256 tokens.
